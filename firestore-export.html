Firestore Export

Reads everything out of the EduQuestHermes project and saves it as one JSON file.

This only reads. Nothing is written, changed or deleted. It uses the same public config already committed in your HTML files — no admin key, no service account. If a collection is empty or blocked by your security rules, it says so and carries on.
Ready. Press "Start export".
Why does it ask me to sign in?

Only if your security rules require it. Firestore can't list collection names from a browser — that's an admin-only operation — so this walks the specific paths your activity files use. If a read comes back "permission denied", signing in with your teacher account usually fixes it. If it still fails, the rules are locked tighter than the apps need, which is worth knowing on its own.
